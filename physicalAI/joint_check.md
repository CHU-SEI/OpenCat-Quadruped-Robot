# 関節番号の確認表

目的: ファームウェアの関節番号 8〜15 が、どの脚のどの関節か、正の角度でどちらに動くかを確かめる。

## 手順

シリアルモニタの `i 8 60` は使わない。直前のスキル（`kbalance`）の上で実行され、ジャイロの姿勢補正が他の脚も動かすため、1つの関節だけを見分けられない。代わりに `joint_check.py` を使う（`L` コマンドは補正を通らない）。

1. Arduino IDE のシリアルモニタなど、COM ポートを使っているものを閉じる。
2. バッテリーを繋ぎ、ロボットを平らな場所に置く。電源スイッチに手が届く位置にいる。
3. 実行する: `python physicalAI\joint_check.py COM4`
4. ロボットが立つ（`kbalance`）。Enter を押すたびに、関節 8〜15 が1つずつ 25° 動いて戻る。
5. **どの脚のどの関節が動いたか**と、**動いた向き**を、下の表の「実測」の欄に書く。
6. 脚が変な姿勢で止まったり、サーボが唸り続けたりしたら、`Ctrl+C` で止め、電源スイッチを切る。

送る角度は、立った姿勢の角度（肩・膝とも約 30°）に 25° を足した値です。ファームウェアの上限を超える場合は、引いた値になります。画面に、送った角度の符号（+ か -）が出ます。「動いた向き」は、その符号とあわせて書いてください。

## 向きの目安（私の予想）

- 肩（8〜11）: 正の角度で、**ももが後ろへ振れる**（脚の下端が尻尾の方へ動く）。
- 膝（12〜15）: 正の角度で、**すねが後ろ・下へ振れる**（足先が尻尾の方へ動く）。

## 記入表

| 番号 | 送るコマンド | 予想（どの関節か） | 実測（どの脚のどの関節が動いたか） | 動いた向き（前 / 後ろ） |
|---|---|---|---|---|
| 8  | `i 8 60`  | 左前の肩 |  |  |
| 9  | `i 9 60`  | 右前の肩 |  |  |
| 10 | `i 10 60` | 右後の肩 |  |  |
| 11 | `i 11 60` | 左後の肩 |  |  |
| 12 | `i 12 60` | 左前の膝 |  |  |
| 13 | `i 13 60` | 右前の膝 |  |  |
| 14 | `i 14 60` | 右後の膝 |  |  |
| 15 | `i 15 60` | 左後の膝 |  |  |

「左」「右」は、**ロボットが前（頭の方）を向いたとき**の、ロボット自身の左右です。ご自分から見た左右ではありません。

## 書き方の例

| 番号 | 実測 | 動いた向き |
|---|---|---|
| 8 | 左前の肩（ももが動いた） | 後ろ |
